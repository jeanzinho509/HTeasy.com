## 2026-07-02 - Mass Assignment / Privilege Escalation in User Registration
**Vulnerability:** The `register` function in `auth.controller.js` extracted the `role` field from the request body (`const { ..., role } = req.body;`) and assigned it to the new user without any authorization checks. This mass assignment vulnerability allowed any malicious user to register an account with elevated privileges (e.g., `role: 'admin'`).
**Learning:** Destructuring request bodies and using the extracted properties directly for sensitive database fields (like user roles, permissions, or balances) is a critical security risk. The `register` endpoint should only allow creation of standard user accounts, while a separate, authenticated, and authorized endpoint should handle granting elevated roles.
**Prevention:** Never destructure and use sensitive fields directly from the request body without validation and authorization checks. For registration, hardcode default privileges (e.g., `const userRole = 'user';`). Use dedicated, admin-only endpoints to manage user roles.
