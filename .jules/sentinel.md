## 2024-05-15 - Privilege Escalation via Registration Payload
**Vulnerability:** A Mass Assignment / Privilege Escalation vulnerability was found in `server/controllers/auth.controller.js` within the `register` function. The code destructured `role` from `req.body` and used it directly or implicitly if provided, allowing any user to register themselves as an 'admin' simply by supplying a `{"role": "admin"}` parameter in their registration POST request.
**Learning:** This existed because of indiscriminate acceptance of client input for sensitive fields. Destructuring all fields from a request payload and using them without explicit mapping and validation leaves an application prone to mass assignment vulnerabilities.
**Prevention:** Always explicitly define which properties are allowed to be modified or initialized by the user. Hardcode defaults for sensitive properties (like role assignments) server-side and ensure only authenticated administrative flows can alter those fields.
