## 2024-05-10 - Path Traversal Vulnerability in File Deletion\n**Vulnerability:** The `/api/upload` DELETE endpoint (`deleteImage`) was vulnerable to Critical Path Traversal. An attacker could provide an `imageUrl` containing `../` characters (e.g., `../../.env`), which when concatenated with the `UPLOAD_DIR`, would resolve to paths outside the upload directory, allowing arbitrary file deletion on the server.\n**Learning:** Node's `path.join` normalizes paths but does not restrict them to the base directory. When handling file deletion or access based on user input, simply removing a prefix (like `/uploads/`) is insufficient because the remaining string can still traverse upwards using `../`.\n**Prevention:** Always validate that the final, resolved absolute path (`path.resolve()`) starts with the absolute path of the intended base directory to guarantee the operation remains within bounds.
