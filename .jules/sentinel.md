## 2026-05-02 - [Path Traversal in Image Deletion]
**Vulnerability:** The image deletion functionality in `server/controllers/upload.controller.js` accepts user-provided file paths directly from an image URL to delete the image from the server. By passing a URL with path traversal characters (e.g. `/uploads/../../.env`), an authenticated attacker could delete arbitrary files on the server, potentially causing denial of service or configuration deletion.
**Learning:** The path provided by `imageUrl.replace('/uploads/', '')` was concatenated using `path.join()` without verifying whether the resulting absolute path stays within the intended `UPLOAD_DIR`. Because `path.join()` allows `..` segments to traverse up, it permitted deleting files outside the upload directory.
**Prevention:** To avoid this, resolve the final path using `path.resolve()` and explicitly check if it starts with the absolute directory path using `resolvedPath.startsWith(path.resolve(UPLOAD_DIR))`. Do not delete the file if it points outside the directory.
