## 2024-05-08 - Path Traversal Vulnerability in Image Deletion
**Vulnerability:** A critical Path Traversal vulnerability existed in `server/controllers/upload.controller.js` within the `deleteImage` function. The endpoint accepted a user-provided `imageUrl` (e.g., `/uploads/../../package.json`), stripped the `/uploads/` prefix, and concatenated the remaining string using `path.join(UPLOAD_DIR, urlPath)`. It then passed the path to `fs.unlinkSync()`, allowing arbitrary files on the server to be deleted.
**Learning:** Concatenating user-supplied input to a base directory using `path.join` is insufficient to prevent traversal because `path.join` natively resolves `../` operators, resulting in paths outside the base directory. We must always validate the fully resolved absolute path.
**Prevention:** Always use `path.resolve` to determine the absolute paths of both the intended base directory and the target file. Subsequently, verify that the resolved target file path strictly begins with the resolved base directory path (including a trailing separator, `path.sep`, to prevent partial directory name matches) before interacting with the filesystem.
