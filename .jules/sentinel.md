## 2024-05-19 - Missing File Extension Validation and Path Traversal in File Upload/Deletion
**Vulnerability:** The application allowed uploading files with arbitrary extensions (e.g., `.html` instead of `.png`) because the file extension from `req.file.originalname` was blindly trusted. In addition, the `deleteImage` endpoint suffered from a potential path traversal vulnerability because the extracted file path from the `imageUrl` was joined directly with `UPLOAD_DIR` without validation.
**Learning:** Even if `multer` checks MIME types in memory, file extensions extracted manually must be strictly validated against a whitelist to prevent stored XSS and other upload-related attacks. For file deletion, always resolve the path absolutely and use `startsWith` to ensure it falls within the intended directory to prevent deleting arbitrary files using `../` in the URL.
**Prevention:** Implement a helper function like `getSafeExtension` that strictly validates `path.extname().toLowerCase()` against a whitelist of allowed extensions. Always use `path.resolve()` and `startsWith()` checks when deriving server-side paths from user-provided URLs or filenames.
